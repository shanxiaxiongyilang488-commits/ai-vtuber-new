# Validation Matrix

This file is reserved for post-generation review and is not part of the stage-one generation context.

| Area | Pass condition |
| --- | --- |
| Identity | Character remains recognizable against profile and references. |
| Head unit | Mechanical cat-ear units are present, correctly mounted, and not biological. |
| Tail unit | Tail is segmented and robotic, with a plausible connection point. |
| Critical features | Every registered critical feature is visible when framing permits. |
| Exclusions | No `avoid` item or duplicated anatomy appears. |
| Coherence | Materials, joints, ports, and articulation form a buildable system. |
