# Design Contract

- Preserve the character profile, visual memory, and supplied reference images as the identity source of truth.
- Represent cat motifs as engineered components: articulated housings, sensors, seams, joints, ports, and serviceable assemblies.
- Never convert a specified mechanical ear unit into biological ears or a segmented robotic tail into fur.
- Keep attachment points and silhouette readable. The tail connects through a visible rear-waist connection system when that feature is registered.
- Preserve registered colors, materials, glow lines, proportions, outfit, accessories, and every `mustKeep` feature.
- Exclude items listed in `avoid`. Do not invent conflicting anatomy or duplicate appendages.
- Adapt pose, camera, environment, and rendering style to the user request without redesigning the character's core hardware.
