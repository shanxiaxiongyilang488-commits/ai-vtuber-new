# Prompt Patterns

Compose concise image instructions in this order:

1. Identity: name the depicted character and state that registered design evidence is authoritative.
2. Mechanical construction: describe visible assemblies, articulation, material transitions, seams, ports, and connection points.
3. Invariants: restate only the relevant `mustKeep` and `avoid` constraints from the character design profile.
4. Requested scene: preserve the user's action, pose, framing, environment, mood, and style.
5. Reference discipline: use attached images for identity and construction consistency, not as permission to add unrelated subjects.
6. Output discipline: request one coherent design with readable silhouette and no duplicated ears, tails, limbs, or accessories.

Prefer positive, concrete construction language. Add negative constraints only for likely identity-breaking substitutions.
