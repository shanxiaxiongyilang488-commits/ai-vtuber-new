# 🏠 AI住人と共同制作する実験室

『ここはネコ型アンドロイド達が集う場所』
アンドロイド（ロボ娘）が好きな管理人RootS（るーつ）が自作したネコ型アンドロイド達をAI住人として一緒に暮らしながら、記憶・成長・画像・動画を育てるチャットと制作空間です。

これは一般的なAIチャットではありません。

AI住人達の生活感や創作活動を観察しながら、一緒に作品を作ることを目的にしています。

🛠️ 使用技術

- Svelte5
- TypeScript
- OpenAI API
- FAL API
- Ollama（予定）
- TTS（Irodoriなど）
